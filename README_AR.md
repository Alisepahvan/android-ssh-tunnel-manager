# SSH Tunnel Manager - تطبيق إدارة أنفاق SSH للأندرويد

## نظرة عامة

تطبيق احترافي وآمن لإدارة اتصالات SSH وإعادة توجيه المنافذ على أجهزة Android. يوفر واجهة مستخدم حديثة وسهلة الاستخدام مع دعم كامل لإدارة السيرفرات والاتصالات.

## المميزات الرئيسية

- 🔐 **إدارة الاتصالات**: إضافة وتعديل وحذف سيرفرات SSH
- 🔑 **المصادقة المزدوجة**: دعم كلاً من كلمات المرور والمفاتيح الخاصة
- 🛡️ **إعادة توجيه المنافذ**: تكوين إعادة التوجيه المحلي والبعيد
- 💾 **التخزين المحلي**: حفظ جميع الإعدادات محليًا باستخدام قاعدة بيانات Room
- 🎨 **واجهة حديثة**: مبنية باستخدام Jetpack Compose و Material Design 3
- 📱 **تصميم ديناميكي**: يعمل بسلاسة على جميع أجهزة Android
- 🔄 **حالة فورية**: مراقبة حالة الاتصال في الوقت الفعلي
- 📢 **إشعارات**: تنبيهات بحالة الاتصال

## البنية المعمارية

التطبيق يتبع نمط MVVM (Model-View-ViewModel):

```
data/                          # طبقة البيانات
├── SshServerEntity.kt         # كيان Room
├── SshServerDao.kt            # كائن الوصول إلى قاعدة البيانات
└── AppDatabase.kt             # تكوين قاعدة البيانات

repository/                    # طبقة الوصول إلى البيانات
└── SshServerRepository.kt

service/                       # خدمات
├── SshTunnelManager.kt        # إدارة اتصالات SSH
└── SshForegroundService.kt    # خدمة الخلفية

viewmodel/                     # نماذج العرض
└── SshViewModel.kt

ui/                           # واجهة المستخدم
├── screens/
│   ├── HomeScreen.kt
│   └── AddEditServerScreen.kt
├── navigation/
│   └── Navigation.kt
└── theme/
    ├── Theme.kt
    ├── Color.kt
    └── Type.kt

di/                           # الحقن المتكامل
└── Module.kt

util/                         # أدوات مساعدة
└── ServiceManager.kt
```

## التثبيت والإعداد

### المتطلبات

- Android Studio Giraffe أو أحدث
- Android SDK 24+ (المستوى 24)
- Kotlin 1.9.20+
- Java 17+

### استنساخ المستودع

```bash
git clone https://github.com/Alisepahvan/android-ssh-tunnel-manager.git
cd android-ssh-tunnel-manager
```

### البناء والتشغيل

```bash
# فتح في Android Studio ومزامنة ملفات Gradle
# أو البناء من المحطة الطرفية
./gradlew build

# التثبيت على الجهاز/المحاكي
./gradlew installDebug
```

## الاستخدام

### إضافة سيرفر

1. اضغط على زر **+** في شاشة الرئيسية
2. أدخل تفاصيل السيرفر:
   - اسم السيرفر
   - عنوان IP أو اسم المضيف
   - منفذ SSH (الافتراضي: 22)
   - اسم المستخدم
3. اختر طريقة المصادقة:
   - **كلمة المرور**: أدخل كلمة المرور
   - **المفتاح الخاص**: ألصق محتوى المفتاح الخاص
4. قم بتكوين إعادة توجيه المنافذ:
   - المنفذ المحلي (الافتراضي: 1080)
   - المضيف البعيد (الافتراضي: 127.0.0.1)
   - المنفذ البعيد (الافتراضي: 80)
5. اضغط **حفظ السيرفر**

### الاتصال بسيرفر

1. حدد سيرفراً من القائمة
2. اضغط **اتصال**
3. انتظر إنشاء الاتصال
4. ستظهر شارة "متصل" عند النجاح

### التعديل والحذف

- اضغط **تعديل** لتغيير إعدادات السيرفر (فقط عندما يكون معطّلاً)
- اضغط **حذف** لإزالة سيرفر (فقط عندما يكون معطّلاً)

## الفئات الرئيسية

### SshViewModel
- إدارة حالة واجهة المستخدم باستخدام StateFlow
- التعامل مع عمليات السيرفر (إضافة، تعديل، حذف)
- إدارة الاتصالات

### SshTunnelManager
- معالجة الاتصالات باستخدام مكتبة JSch
- إدارة إعادة توجيه المنافذ
- التحكم في دورة الحياة (اتصال/قطع)

### SshServerRepository
- تجريد عمليات قاعدة البيانات
- توفير البيانات لـ ViewModel عبر Flow

### AppDatabase
- حالة Singleton لقاعدة البيانات
- تعريفات DAO
